# Proteus

一个在浏览器里运行的角色扮演聊天工具，可以接入大语言模型（LLM），玩法类似 SillyTavern。

![界面截图](docs/screenshot.png)

## 怎么打开

不需要安装任何东西：

1. 下载整个文件夹（GitHub 页面上的 **Code → Download ZIP**，然后解压）
2. 双击 `index.html`，用 Chrome 或 Edge 打开即可

> 所有数据（设定、对话、图片、API Key）都只保存在**这台电脑的这个浏览器**里。
> 换浏览器、换电脑，或者清除浏览器数据都会看不到原来的内容，所以请定期用右侧的「完整备份」导出一份。

## 界面

| 区域 | 作用 |
|---|---|
| 左栏 | 艺术图。点击即可上传，推荐用竖版图片 |
| 中栏 | 剧情区。顶部可以切换、新建、重命名、删除对话；底部是输入框，按 **Ctrl + Enter** 发送 |
| 右栏 | 设置，从上到下依次是：System Prompt → 世界观 → 用户角色人设 → 记忆长度 → 模型与接口 → 艺术图 → 导出与备份 |

### 开场白

在一个空对话里发送第一条消息时，会弹出一个窗口询问"是否作为开场白发送并保存"：

- **作为开场白保存**：这段内容会固定显示在对话最上方，**不会马上发给模型**。你下一次发送消息时，开场白会和那条消息合在一起，作为第一条消息发给模型，格式如下：
  ```
  【开场白】
  ……开场白内容……

  【用户】
  ……你这次的消息……
  ```
  剧情推进到第一条消息超出记忆长度后，开场白也会随之超出，不再发送。
- **直接发送给模型**：作为普通消息马上发送，这个对话就不设开场白。
- **取消**：什么都不做，内容留在输入框里。

开场白可以编辑或删除，导出、备份和从备份恢复时都会一起保留。

### Markdown 和 HTML 美化

开场白、你的回复和模型的回复都会按 Markdown 和 HTML 显示，可以使用 `<details><summary>` 折叠块、自定义样式（`<style>`、`style="..."`），甚至 `<script>` 脚本。

每条消息都显示在一个独立的"沙箱"小窗口里：

- 消息里的样式和脚本只在这条消息里生效，不会影响聊天区以外的界面，也不会影响其他消息；
- 脚本读不到本页面的任何数据（包括 API Key），也不能弹窗或跳转页面；
- 模型生成过程中，消息里的脚本暂时不运行，生成结束后才会运行。

### 消息操作（鼠标移到消息上就会出现）

- **重新生成**：只出现在最后一条模型回复上。旧版本会保留，可以用 `‹ 2/3 ›` 来回切换
- **删除此版本**：消息有多个版本时，删掉当前显示的这个
- **编辑**：模型的回复和你自己的回复都可以直接改，之后发给模型的就是改过的内容
- **回退到此前**：删掉这条消息以及之后的所有消息。如果回退的是你自己的消息，原文会放回输入框，方便修改后重发
- **复制**

模型生成期间可以随时往上滚动阅读，页面不会被强行拉回底部；想回到最新内容时，点「↓ 回到底部」。

## 每次发给模型的内容

```
[system]  System Prompt + 世界观全文 + 用户角色人设
[历史]    最近 N 轮剧情（N = 记忆长度，8–16 轮；1 轮 = 模型一次输出 + 你一次回复）
          如果对话的第一条消息还在范围内，开场白会拼在它前面
[user]    你这一次的回复
```

更早的消息不会发送，模型也就"看不到"它们。剧情区里，超出记忆范围的旧消息会变淡显示，并用一条虚线标出分界。
点击「查看下一次将发送的内容」可以看到下一次请求的完整内容。

## 支持的模型服务商

| 选项 | 说明 |
|---|---|
| Anthropic（Claude 官方） | 直接调用 Claude。已启用提示词缓存：世界观等固定内容会被缓存，后续请求更便宜、更快 |
| OpenAI 官方 | |
| OpenRouter | 一个 Key 就能用很多家的模型。用 `anthropic/` 开头的 Claude 模型时同样会启用缓存 |
| 其他 OpenAI 兼容接口 | DeepSeek、各种中转站等。需要自己填写接口地址，通常以 `/v1` 结尾 |
| 其他 Anthropic 兼容接口 | 提供 Claude 原生格式的中转站 |

点击「获取列表」可以从接口拉取可用的模型名称。

### 关于 Claude 官方接口

- 使用最新的 API 版本。这个版本不接受 `temperature` 参数，所以 Anthropic 格式下没有这个选项，改为提供「思考深度（effort）」
- 新的 Claude 模型会先思考再输出，所以开头可能要等几秒，界面上会显示「模型思考中……」
- 对 `claude-opus-5-5`、`claude-sonnet-5-5` 等模型启用了官方的自动备用：如果请求被安全机制拦截，接口会自动换一个模型重试。如果最终仍被拒绝，界面上会显示提示

### 如果提示「无法连接到接口」

浏览器出于安全考虑，会拦截一部分直接访问外部接口的请求（"跨域限制"）。Claude 官方、OpenAI 官方和 OpenRouter 都允许浏览器直接访问；少数中转站不允许。以后套上 Electron 外壳，就不会再有这个限制。

## 文件结构

```
index.html        页面结构
css/style.css     样式
js/db.js          本地存储（浏览器的 IndexedDB）
js/providers.js   和各家模型接口通信
js/render.js      消息显示（Markdown/HTML，沙箱隔离）
js/app.js         界面逻辑、对话管理、上下文拼装
js/vendor/        第三方库（marked：Markdown 解析，MIT 许可）
```

全部是普通的 HTML/CSS/JavaScript，不需要编译，以后可以直接放进 Electron 里运行。
